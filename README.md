# AI Resume Analyzer

## Overview

AI Resume Analyzer is a Streamlit web application that analyzes resumes and provides ATS scores, company match scores, and skill recommendations.

## Features

- Resume Upload (PDF)
- Resume Text Extraction
- Skills Detection
- ATS Score Calculation
- Missing Skills Analysis
- Google Match Score
- Infosys Match Score
- TCS Match Score
- Deloitte Match Score
- Skill Recommendations
- Downloadable Resume Report

## Technologies Used

- Python
- Streamlit
- PDFPlumber

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```
